# Tarot Correspondence Drill

A single-page study tool for Thoth and Rider–Waite–Smith correspondences.

## Publish on GitHub Pages
1. Create a public repository (for example `tarot-drill`).
2. Upload every file in this folder to the top level of the repository and commit.
3. Settings → Pages → Build and deployment → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
4. After a minute the app is live at `https://<your-username>.github.io/tarot-drill/`.

## Install on a phone
Open the address in Chrome, then tap "Install app" next to the subtitle (or ⋮ → Add to Home screen).

## Updating
Upload the new `index.html` over the old one. If you change `sw.js`, bump the `VERSION` line at the top.

## Your progress
Progress is stored in the browser on each device. Use Progress → "Save progress file" / "Load progress file" to back it up or move it between devices.
